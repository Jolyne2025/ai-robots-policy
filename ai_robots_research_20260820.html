主流网站 robots.txt 对 AI 搜索引擎/爬虫策略调研报告

样本覆盖电商、B2B 平台、新闻媒体、社区、科技公司等 13 个站点,并对标 wlw.de 与 alibaba.com
📅 调研日期:2026-08-20 🔬 方法:抓取各站 robots.txt 原文 + 行业公开研究数据 🎯 目的:为 wlw.de GEO / AI 可见度策略提供参照

一、核心结论(速览)

  1. 行业已分化成 5 种策略模式,从"全屏蔽"到"全放行"光谱分布,B2B 平台整体最开放(wlw.de / Europages / DHGate / Made-in-China 均放行 AI 爬虫),新闻媒体最保守(约 79% 屏蔽 AI 训练爬虫)。
  2. 2025 年出现新趋势——"训练屏蔽、搜索放行":eBay 率先把 LLM 训练型爬虫(GPTBot、ClaudeBot、PerplexityBot)与 AI 搜索型爬虫(OAI-SearchBot、ChatGPT-User、Claude-SearchBot)分组对待:前者只给少量官方页,后者可抓全部商品页。
  3. Alibaba 是特例:默认组未全屏蔽,但单独把 GPTBot 和 Google-Extended 关进黑名单——对 AI 训练态度保守,对未具名爬虫反而开放。
  4. wlw.de 属于最激进的"拥抱派":与 Europages 共用同一套 robots 模板(同 CMS 架构),21 个白名单 UA 全部放行全站,未列名爬虫一律屏蔽。

三、五大策略模式详解

模式 A:默认全关,白名单全开(拥抱派)

代表:wlw.de、europages.co.uk、dhgate.com(局部)

# wlw.de 模式
User-agent: *
Disallow: /

User-agent: Googlebot / bingbot / GPTbot / ChatGPT-User / OAI-SearchBot / PerplexityBot / Google-Extended / SemrushBot / Botify ...
Allow: /

特征:所有未具名爬虫整站屏蔽;显式放行的白名单(含全部主流 AI 爬虫 + SEO 工具)可抓全站。

逻辑:把 AI 引擎视为与 Google 同级的流量渠道,主动拥抱以换取 AI 引用可见度(与 GEO 目标一致);屏蔽杂牌爬虫以保护服务器资源与内容质量。

模式 B:AI 爬虫全部拒绝(保守派)

代表:Amazon(~80 个 UA 黑名单)、CNN(~70 个)、wikiHow(附法律声明)

# Amazon 模式(摘录)
User-agent: GPTBot / CCBot / PerplexityBot / Google-Extended / ClaudeBot / ChatGPT-User / OAI-SearchBot / GrokBot / DeepSeekBot / Bytespider / ...
Disallow: /

特征:黑名单覆盖几乎所有已知 AI 爬虫(训练型 + 搜索型一刀切),但 Googlebot / bingbot 等搜索引擎爬虫不受影响。

逻辑:担心内容被免费用于训练或 AI 摘要分流流量;wikiHow 甚至附加了"禁止用于 AI 训练/检索,违者违反服务条款"的法律声明。

模式 C:训练屏蔽、搜索放行(精细化派 ⭐ 2025-26 新趋势)

代表:eBay(最典型)、IndiaMART(近似)

# eBay 模式(摘录)
# LLM / AI bot directives —— 训练型:整站拒绝,只给少量官方页
User-agent: GPTBot / PerplexityBot / ClaudeBot / anthropic-ai / CCBot / Bytespider / Applebot-Extended / meta-externalagent ...
Disallow: /
Allow: /help  /sellercenter  /motors/blog  /giftcards ...

# AI 搜索型:与搜索引擎同权,可抓全部商品页
User-agent: OAI-SearchBot / ChatGPT-User / Claude-SearchBot / Claude-User
(继承 * 组的全部 Allow/Disallow 规则)

特征:明确区分两类 AI 爬虫:

  • 训练型(GPTBot、ClaudeBot、PerplexityBot、anthropic-ai、CCBot 等)→ 屏蔽,只放行少量品牌/帮助页面;
  • 搜索型(OAI-SearchBot、ChatGPT-User、Claude-SearchBot)→ 与普通搜索引擎同等权限,可抓商品详情页。

逻辑:AI 搜索引用能带来真实流量(属于 GEO 收益),但免费训练则是纯成本——"引用欢迎,训练免谈"。

模式 D:定向白名单 + 限速(工程派)

代表:Global Sources(每个 AI 爬虫独立一组 + crawl-delay 10~20s)、Made-in-China(AI 大组白名单)

# Global Sources 模式(摘录)
User-agent: PerplexityBot / Perplexity-User
Allow: /$   /category/   /knowledge/   /helpCenter/   /*/company-profile   /*p.htm   /*.xml*
Disallow: /
Crawl-delay: 20

# Made-in-China 模式(摘录)
User-agent: GPTBot / OAI-SearchBot / ChatGPT-User / Google-Extended / ClaudeBot / GrokBot / PerplexityBot / Applebot-Extended / CCBot ...
Allow: /products-search/   /manufacturers/   /factory/   /help/   /faq/
Disallow: /products-search/ai-mode/

特征:AI 爬虫可抓,但只开放"核心索引资产"子集(类目页、公司档案、知识库),并设置爬取延迟保护资源;Made-in-China 甚至把自家的 AI 搜索功能页单独屏蔽。

逻辑:既要 AI 可见度,又要控制爬取成本与服务器负载——用 Allow 白名单而非 Disallow 黑名单来表达"欢迎但有限"。

模式 E:不特别处理(佛系派/早期默认态)

代表:GitHub、Alibaba 的默认组

特征:robots.txt 中没有 AI 爬虫专属规则,AI 爬虫与所有未具名爬虫共用默认组(通常只屏蔽功能页/参数页,主体内容默认可抓)。

逻辑:可能是历史遗留(2023 年前的默认状态)、不想维护庞大黑名单,或认为屏蔽对 AI 可见度弊大于利。注意 Alibaba 是"模式 E 的变体":默认组开放,但单独把 GPTBot 和 Google-Extended 拉黑——宁可让杂牌爬虫抓,也不让 OpenAI 训练。

五、关键洞察与对 wlw.de 的启示

洞察 1:B2B 平台是 AI 爬虫政策最开放的行业

  • 样本内 6 个 B2B/跨境平台中,5 个(wlw、Europages、DHGate、Made-in-China、Global Sources、IndiaMART 部分)对 AI 搜索爬虫持放行态度,与新闻媒体(79% 屏蔽)形成鲜明反差。
  • 原因推测:B2B 平台的询盘/供应商线索价值高,AI 引用带来的精准 B2B 流量转化价值大;且 B2B 内容(公司档案、产品目录)对 AI 训练的商业威胁感弱于新闻内容。

洞察 2:"训练/搜索二分法"是 2026 年的行业新共识

  • eBay 的分级模式(训练型屏蔽、搜索型放行)正在成为精细化标杆;wikiHow/Amazon 的一刀切屏蔽反而显得过时——因为它同时放弃了 AI 搜索的引用流量。
  • wlw.de 目前对训练型(GPTBot/ClaudeBot/PerplexityBot)与搜索型(OAI-SearchBot/ChatGPT-User)一视同仁全部放行,若担心内容被免费训练,可借鉴 eBay 做分级。

洞察 3:wlw.de 与 Europages 共享同一 robots 模板

  • 两者规则几乎逐行一致(白名单 UA 完全重合、Disallow 列表同构),确认是同一 CMS/运营团队管理——这意味着模板化改动的波及面是两站,需要一并评估。

洞察 4:阿里是"反向操作"的特例,值得关注其效果

  • Alibaba 屏蔽 GPTBot/Google-Extended 但放行 Perplexity(落默认组)——它的 AI 引用流量结构可能与 wlw 完全不同(Perplexity 占比高、ChatGPT 占比低)。
  • 结合之前的 alibaba_geo 截图,若其 GEO 流量表现依旧强劲,说明"选择性屏蔽"不会明显伤害 AI 可见度,可作为 wlw 决策的参考证据。

洞察 5:技术性细节值得学习

  • 限速:Global Sources 给 AI 爬虫加 Crawl-delay 10~20s,WLW 目前无此设置——AI 爬虫突发抓取可能挤压服务器资源;
  • 路径白名单:Made-in-China 只开放核心索引资产(/products-search/、/manufacturers/、/factory/),WLW 是"全站开放 + 黑名单"思路,可对比评估是否值得改为白名单;
  • 法律声明:wikiHow 在 robots.txt 顶部附版权/训练禁令声明(虽无强制力,但有诉讼辅助价值),WLW 可考虑补充。

六、wlw.de 可选优化方向(供讨论)

方向 做法 风险/收益
维持现状 白名单全放行 AI 爬虫 GEO 可见度最大化;风险是内容可被免费训练,AI 摘要可能分流点击
学习 eBay 分级 训练型(GPTBot/ClaudeBot/PerplexityBot)→ 屏蔽或仅放品牌页;搜索型(OAI-SearchBot/ChatGPT-User/Claude-SearchBot)→ 维持全站 平衡训练风险与引用流量;改动小(仅需调整分组)
